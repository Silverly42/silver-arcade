# Gravebound Knight

An original clean-room browser action-platformer built with HTML5 Canvas and plain JavaScript.

## Run

From the Silver Arcade root:

```sh
npm start
```

Open <http://localhost:4173/games/gravebound-knight/>.

## Controls

- Move: A/D or Left/Right
- Jump/climb: W, Up, or Z
- Crouch/descend: S or Down
- Fire: Space or X
- Pause: P or Escape
- Touch controls appear on touch-first devices.
